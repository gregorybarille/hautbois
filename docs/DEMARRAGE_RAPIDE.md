# 🚀 Démarrage Rapide - Cartes-Partition

## En 3 Minutes Chrono ! ⏱️

### 1️⃣ Lancer l'Application

```bash
npm install
npm run dev
```

Ouvrez votre navigateur : **http://localhost:5173**

### 2️⃣ Accéder à Cartes-Partition

```
Menu Principal → Cliquez sur "Cartes - Partition"
```

### 3️⃣ Commencer l'Exercice

1. **Autorisez le microphone** (popup du navigateur)
2. **Cliquez sur "🎤 Commencer à dicter"**
3. **Regardez la note en bleu** (celle qui pulse)
4. **Dites le nom de la note** : "do", "ré", "mi", etc.
5. **Continuez** jusqu'à la fin des 10 notes
6. **Consultez votre score** !

---

## 🎯 Exemple d'Utilisation

```
Partition affiche : Sol (note en surbrillance bleue)
Vous dites     : "sol"
Résultat       : ✓ CORRECT → Note devient verte
Passage        : Automatique à la note suivante
```

---

## 🎤 Comment Prononcer les Notes

| Note | Dites simplement |
|------|------------------|
| Do   | "do" |
| Ré   | "ré" ou "re" |
| Mi   | "mi" |
| Fa   | "fa" |
| Sol  | "sol" |
| La   | "la" |
| Si   | "si" |

Pour les notes altérées :
- **Do#** → "do dièse" ou "do diese"
- **Si♭** → "si bémol" ou "sib"

## ⚠️ Problèmes Courants

### Le micro ne marche pas ?
→ Vérifiez les permissions du navigateur (icône 🔒 dans la barre d'adresse)

### Ça ne reconnaît pas ma voix ?
→ Parlez plus fort et clairement
→ Ou utilisez les boutons "✓ Correct" / "✗ Incorrect"

### Quel navigateur utiliser ?
→ **Chrome** (recommandé) ou **Edge** ou **Safari**
→ ❌ PAS Firefox (non compatible)

---

## 📱 Sur Mobile

Même principe, mais :
- Autorisez le micro sur votre téléphone
- Utilisez Chrome Mobile ou Safari iOS
