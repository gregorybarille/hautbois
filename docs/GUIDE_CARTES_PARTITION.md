# Guide d'Utilisation - Cartes-Partition 🎵

## Vue d'ensemble

L'exercice **Cartes-Partition** vous aide à améliorer votre lecture de partition en combinant reconnaissance visuelle des notes et dictée vocale. C'est un outil interactif parfait pour développer vos compétences en solfège !

## Comment ça marche ?

### 1️⃣ Démarrage de l'exercice

- Depuis le menu principal, cliquez sur **"Cartes-Partition"**
- Une série de **10 notes aléatoires** est automatiquement générée
- Les notes sont affichées sur une portée musicale en clé de Sol

### 2️⃣ Activation du microphone

1. Cliquez sur le bouton **"🎤 Commencer à dicter"**
2. Autorisez l'accès au microphone si votre navigateur le demande
3. Le bouton devient rouge quand le microphone est actif : **"🔴 Arrêter"**

### 3️⃣ Dicter les notes

- **Regardez la note en surbrillance bleue** (avec animation pulsante)
- **Prononcez le nom de la note** clairement :
  - "Do"
  - "Ré"
  - "Mi"
  - "Fa"
  - "Sol"
  - "La"
  - "Si"
- Le système reconnaît aussi les variantes :
  - "Do dièse" ou "Do#"
  - "Mi bémol" ou "Mib"

### 4️⃣ Validation automatique

- Dès que vous prononcez la note, elle apparaît en temps réel sous "🎤 Vous avez dit :"
- Le système valide automatiquement votre réponse
- **✓ Vert** = Bonne réponse
- **✗ Rouge** = Mauvaise réponse
- La note suivante est mise en surbrillance automatiquement

### 5️⃣ Validation manuelle (optionnelle)

Si la reconnaissance vocale ne fonctionne pas bien :
- Utilisez le bouton **"✓ Correct"** pour marquer une note comme juste
- Utilisez le bouton **"✗ Incorrect"** pour marquer une note comme fausse

### 6️⃣ Progression et Score

En haut de l'écran, vous voyez :
- **Progression** : 3 / 10 (note actuelle sur total)
- **Badge vert** : Nombre de bonnes réponses
- **Badge rouge** : Nombre de mauvaises réponses
- **Barre de progression** : Avancement visuel

### 7️⃣ Fin de l'exercice

Une fois les 10 notes complétées :
- Votre **score final** s'affiche
- Le **taux de réussite** est calculé
- Cliquez sur **"🔄 Nouvelle série"** pour recommencer

## 🔄 Régénérer les notes

À tout moment, vous pouvez :
- Cliquer sur **"Générer de nouvelles notes"** pour une nouvelle série
- Votre progression actuelle sera réinitialisée

## 🌐 Compatibilité des navigateurs

### ✅ Navigateurs recommandés
- **Google Chrome** (Desktop & Mobile) - Meilleure compatibilité
- **Microsoft Edge**
- **Safari** (iOS 14.5+ et macOS)

### ❌ Non compatible
- **Firefox** (pas de support de l'API Web Speech)
- Navigateurs obsolètes

> 💡 **Astuce** : Si vous voyez un message d'erreur rouge, utilisez un navigateur compatible.

## 🎯 Conseils pour une meilleure reconnaissance

### Pour améliorer la précision :

1. **Environnement calme** : Réduisez les bruits de fond
2. **Prononciation claire** : Articulez bien les noms des notes
3. **Distance du micro** : Restez à environ 30-50 cm du microphone
4. **Débit régulier** : Ne parlez ni trop vite ni trop lentement
5. **Pause entre les notes** : Attendez la validation avant la note suivante

### Variantes acceptées :

| Note | Prononciations acceptées |
|------|--------------------------|
| Do   | "do", "doh", "c" |
| Ré   | "ré", "re", "d" |
| Mi   | "mi", "e" |
| Fa   | "fa", "f" |
| Sol  | "sol", "g" |
| La   | "la", "a" |
| Si   | "si", "b" |
| Do#  | "do dièse", "do diese", "do sharp" |
| Mib  | "mi bémol", "mi bemol", "mi flat" |

## 🎓 Progresser avec l'exercice

### Niveau débutant
- Concentrez-vous sur la précision plutôt que la vitesse
- Utilisez la validation manuelle si besoin
- Visez 80% de bonnes réponses

### Niveau intermédiaire
- Essayez de dicter sans regarder le nom affiché
- Augmentez votre vitesse de lecture
- Visez 90% de bonnes réponses

### Niveau avancé
- Lisez à vue sans hésitation
- Enchaînez plusieurs séries d'affilée
- Visez 100% de bonnes réponses

## 🐛 Résolution de problèmes

### Le microphone ne s'active pas
- Vérifiez les permissions du navigateur
- Rechargez la page et réessayez
- Vérifiez que votre micro fonctionne

### La reconnaissance ne fonctionne pas
- Vérifiez votre connexion internet (certains navigateurs nécessitent une connexion)
- Parlez plus fort ou plus clairement
- Utilisez la validation manuelle

### Les notes ne s'affichent pas correctement
- Rechargez la page
- Vérifiez que JavaScript est activé
- Essayez un autre navigateur

## 📊 Statistiques

À chaque session, vous pouvez suivre :
- **Score actuel** : Bonnes réponses / Total
- **Taux de réussite** : Pourcentage de succès
- **Progression** : Notes complétées / Total

## 🎵 Notes actuellement supportées

L'exercice utilise les notes du **registre médium** :
- Do, Do#, Ré, Mi♭, Mi, Fa, Fa#, Sol, Sol#, La, Si♭, Si

> Les notes du registre grave et aigu seront ajoutées dans une prochaine version.
